# Which Rules Actually Apply to Tidewell?

> Practice worksheet. Fill in the last two columns yourself using the evidence. Some of these apply, and some don't. Knowing which ones **don't** apply is part of the job, because it stops a company from spending money on the wrong thing.

A **framework** is a list of good practices a company chooses to follow (or a customer asks for). A **regulation** or **contract clause** is something the company *must* follow, with penalties. Mark which is which.
